Задача

Мониторинг промышленного датчика в реальном времени: симулированный датчик → MQTT → БД временных рядов → REST API → веб-дашборд. Учебно-боевой IIoT-проект.

Команда

Кирилл — технический лид, архитектура, фронтенд.
Друг — бэкенд (.NET, PostgreSQL, инфраструктура).

Стек

Python (симулятор) · Mosquitto 2.x · .NET 8 (Worker + Minimal API, план) · PostgreSQL + TimescaleDB (план) · Vue 3 + Vite (дашборд, каркас в main) · Docker Compose.

Статус

Реализовано: MQTT-брокер + симулятор датчика (сборка временно сломана, см. PROJECT.md) + каркас дашборда. Спланировано, кода нет: consumer, БД, REST API.
