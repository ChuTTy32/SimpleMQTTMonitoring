Project Summary

Учебно-боевой IIoT pet-проект: путь от симулированного промышленного датчика до веб-дашборда. Цель — освоить стек (MQTT → Docker → TimescaleDB → .NET → Go → Vue) и заложить фундамент для научной публикации.

Tech Stack

  • Sensor: Python, paho-mqtt
  • Broker: Mosquitto 2.x
  • DB: PostgreSQL + TimescaleDB
  • Consumer: .NET 8 Worker
  • API: Go 1.23, chi, pgx
  • UI: Vue 3, Vite, Tailwind
