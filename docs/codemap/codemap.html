Задача

Мониторинг промышленного датчика в реальном времени: симулированный датчик → MQTT → TimescaleDB → REST API → веб-дашборд. Учебно-боевой IIoT pet-проект, фундамент для магистратуры и Scopus-публикации.

Команда

Кирилл — технический лид, архитектура, фронтенд.
Друг — бэкенд (.NET/Consumer, PostgreSQL, инфраструктура); Go на REST API оба изучают вместе.

Стек

Python (симулятор) · Mosquitto 2.x · Go — chi + pgx + sqlc + JWT (REST API, первая ручка сделана) · .NET 8 Worker (Consumer, план) · PostgreSQL + TimescaleDB (развёрнута в docker-compose) · Vue 3 + Vite (дашборд, каркас) · Docker Compose + Makefile.

Статус

Реализовано: MQTT-брокер + симулятор; TimescaleDB + миграции в docker-compose (config валиден, живой запуск не проверялся); REST API — GET /health (проверено вживую). Спроектировано, не реализовано: полная структура API (CRUD + WebSocket-канал метрик, см. docs/api-architecture.md), Consumer, подключение дашборда.

Источник этой информации и полный актуальный контекст проекта: docs/PROJECT.md (часть правок на момент генерации ещё не запушена — см. плашку «uncommitted changes» в шапке)
